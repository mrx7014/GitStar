# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 2.x | Yes |
| 1.x | No |

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/mrx7014/GitStar/security/advisories/new), not in a public issue. GitStar never requires a GitHub token in the browser; keep local and Actions tokens out of commits.
